# NotesYou · Заметки

Заметки для Android в стиле **Material 3 Expressive** — Kotlin + Jetpack Compose,
настоящие компоненты Google: `MaterialShapes`, `FloatingActionButtonMenu`, `MotionScheme.expressive()`.

## Фишки

**Заметки и списки**
- Текстовые заметки и чек-листы; галочка превращается в повёрнутую печеньку с пружинным «отскоком».
- Отмеченные пункты уезжают вниз в сворачиваемую секцию, прогресс-бар на карточке.
- Превращение заметки в список и обратно одним нажатием.
- Отмена/повтор правок (история до 120 шагов), автосохранение.
- Счётчик слов, символов и строк, время чтения, даты создания и изменения.

**Оформление**
- 11 тональных цветов заметок (подстраиваются под светлую/тёмную тему).
- 16 фигур Material 3 Expressive как значок заметки: печеньки, клеверы, солнца, звёзды, цветок, сердце, самоцвет…
- Тема приложения: обои Material You или 8 пресетов (по умолчанию — древесный), светлая/тёмная/авто.
- Сетка в 2–3 колонки или список, настраиваемое число строк предпросмотра и размер текста.

**Организация**
- Закрепление, архив, корзина (очищается сама через 30 дней), ярлыки (создать, переименовать, удалить).
- Поиск с подсветкой совпадений, фильтр по цвету, 5 видов сортировки.
- Множественный выбор: закрепить, перекрасить, сменить фигуру, ярлыки, архив, удалить — сразу для многих.
- Смахивание карточки — в архив; отмена любого действия из снекбара.
- Напоминания с уведомлениями (быстрые варианты или выбор даты и времени), переживают перезагрузку.

**Анимации**
- Переход «карточка → редактор» (shared element / container transform).
- Экспрессивное FAB-меню, морфинг фигур в пустых состояниях, выборе, свайпе, статистике.
- Поочерёдное появление и анимированная перестановка карточек, плавная смена цвета заметки.

**Ещё**
- «Поделиться» из любого приложения → новая заметка.
- Ярлыки на иконке: «Новая заметка», «Новый список».
- Случайная заметка, статистика (слова, выполненные пункты, цвета, любимый ярлык).
- Экспорт и импорт всех заметок в JSON.

## Сборка

GitHub Actions собирает APK на каждый пуш и публикует его в **Releases**.
Чтобы обновления ставились поверх, добавьте секреты `NOTESYOU_KEYSTORE_BASE64`,
`NOTESYOU_KEYSTORE_PASSWORD`, `NOTESYOU_KEY_ALIAS`, `NOTESYOU_KEY_PASSWORD`.
